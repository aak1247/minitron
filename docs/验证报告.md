## 本机演示

以下命令适用于已生成本机演示源和演示应用的开发目录，源码仓库不包含 `dist/`。新克隆的项目请先按照 README 构建应用，再用发布工具生成 loopback 更新源（`--base-url http://127.0.0.1:8787 --out ./dist/demo-source`）；构建配置使用同一地址的 manifest.json，并传 `-AllowLocalhostHttp`。

在项目根目录的一个终端运行：

```powershell
node scripts/serve-release.mjs --dir ./dist/demo-source --port 8787
```

另一个终端运行，或打开该应用目录中的 shell.exe：

```powershell
./dist/windows/1.0.0/application/shell.exe
```

演示包使用明确允许的 loopback HTTP 源。生产发布应重新生成并托管清单、替换 ManifestUrl，按需配置 Ed25519 公钥和系统代码签名。详细构建/发布命令见 README。
